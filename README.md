A single line that makes office life funny. The house judge reads the lines two at a time and the five best split a $2 reward. Free to enter.

## Run it

```sh
python3 main.py
```

The program writes one joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
